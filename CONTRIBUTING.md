# Mitarbeit

Fehlerberichte und Pull Requests sind willkommen. Bei Fehlern bitte die Anker-Version, Betriebssystem und Schritte zum Nachstellen angeben. Zugangsdaten, private Schlüssel und gesicherte Hostkonfigurationen gehören nicht in Issues.

Änderungen an Sicherung, Wiederherstellung, Anmeldung und Updates brauchen einen Test, der den Fehler oder das neue Verhalten abdeckt. Für die Oberfläche bitte auch prüfen, ob Tastaturbedienung und schmale Fenster noch funktionieren.

Vor einem Pull Request die Prüfungen aus der README ausführen. Größere Änderungen vorher in einem Issue beschreiben, damit wir nicht aneinander vorbeiarbeiten.

Pull Requests ändern das Original erst, wenn ein Maintainer sie übernimmt. Beiträge werden unter der MIT-Lizenz des Projekts veröffentlicht.
